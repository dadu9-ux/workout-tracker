## 🚀 Quick Install (2 Methods)

### **Method 1: GitHub Pages (RECOMMENDED - Permanent Link)**

This gives you a link that works forever and can be accessed from anywhere.

#### **Step 1: Upload to GitHub**

1. **Go to GitHub.com** (on your computer or phone)
   - Sign up free: https://github.com/signup
   
2. **Create New Repository**
   - Click "+" button → "New repository"
   - Name: `workout-tracker`
   - Select **Public** ✓
   - Click "Create repository"

3. **Upload Files**
   - Click "uploading an existing file"
   - Upload these files (drag and drop):
     * `index.html`
     * `manifest.json`
     * `sw.js`
     * All `icon-*.png` files (9 files)
   - Click "Commit changes"

4. **Enable GitHub Pages**
   - Click "Settings" tab
   - Click "Pages" in left sidebar
   - Under "Source": Select **main** branch
   - Click "Save"
   - Wait 1-2 minutes

5. **Get Your Permanent Link**
   - GitHub will show: `https://YOUR-USERNAME.github.io/workout-tracker/`
   - This is your permanent app link!

#### **Step 2: Install on iPhone**

1. **Open Safari** on your iPhone (must use Safari, not Chrome)
2. **Go to your link**: `https://YOUR-USERNAME.github.io/workout-tracker/`
3. **Tap the Share button** (square with arrow pointing up)
4. **Scroll down** and tap **"Add to Home Screen"**
5. **Name it**: "Workout" (or anything you like)
6. **Tap "Add"**

**🎉 Done! You now have a workout app icon on your iPhone!**

## 🔧 Troubleshooting

**Q: I don't see "Add to Home Screen" option**
- You MUST use **Safari** browser (not Chrome or other browsers)
- Make sure you tapped the Share button (not the menu)

**Q: App opens in Safari with toolbar**
- Delete the app icon
- Add to home screen again from Safari
- Make sure you're tapping the app icon, not a bookmark

**Q: Quotes don't change**
- Quotes rotate the **next morning** after you complete a workout
- Mark a workout as "Completed" today
- Check tomorrow morning for a new quote

**Q: My data disappeared**
- Don't clear Safari website data
- Settings → Safari → "Clear History and Website Data" will erase your workout data
- Use "Private Browsing" and your data won't save

**Q: Icons don't show up**
- Make sure you uploaded ALL the icon files to GitHub
- Check that icon files are in the same folder as index.html

**Q: Works online but not offline**
- Open the app once while connected to internet
- This downloads everything for offline use
- Then it works without internet
